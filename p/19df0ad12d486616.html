OpenScreen: 유료 화면녹화의 오픈소스 대체
  • 맥 전용 유료 도구 Screen Studio(월 29달러)의 대안으로 OpenScreen이 깃허브에 공개됨. 윈도우·맥 모두 지원, 워터마크 없음, 상업적 이용 가능.
  • 녹화만 하면 마우스 동선에 맞춘 자동 줌인, 모션 블러, 그림자·둥근 모서리 같은 시각 효과가 자동 적용된다. 데모 영상 품질의 병목이 편집 기술에서 기획으로 옮겨가는 지점.
  • 핵심은 개별 도구가 아니라 흐름이다. 독점적이던 유료 SaaS 기능이 오픈소스로 빠르게 복제되고 있고, 남는 차별점은 무엇을 어떻게 전달할지라는 기획 쪽으로 이동한다.
실제로 써본 한계 (도입 전 확인할 것)
  • 실사용자 보고: 웹캠 동시 녹화 시 웹캠 미리보기가 안 되고, 웹캠 크기 변경도 불가. README에도 명시된 알려진 제약이다.
  • 순수 화면 캡처 용도로는 충분하다는 평. 단순 녹화만 필요하면 OBS로도 되고, 자동 줌·모션 효과 같은 부가 기능을 원할 때 갈아탈 가치가 생긴다.
녹화 도구를 MCP로 감싸 편집까지 자동화
  • 가장 실질적인 응용 사례. Codex Computer Use와 OpenScreen을 붙여 앱 사용 설명 영상을 자동 생성하려다, 트리밍·자막·줌을 사람이 일일이 손봐야 하는 벽에 부딪혀 OpenScreen 코드에 MCP 서버를 내장하는 방향으로 선회했다.
  • 구현 순서가 그대로 재사용 가능한 레시피다. (1) OpenScreen 내부 기능을 목록화하고 각각을 직접 호출하는 MCP 서버 개발(streaming HTTP 방식) (2) 그 MCP 기능 기반으로 OpenScreen 전용 skills 생성 (3) skills에 Codex Computer Use로 녹화 중 timecode 기반 자막과 해당 timecode 편집 함수 호출을 JSON으로 기록하게 지침 추가 (4) 녹화 후 그 JSON 기록을 재생해 편집을 수행.
  • 일반화하면 GUI 앱의 기능을 목록화해 MCP로 노출하고, 에이전트가 timecode·좌표 같은 구조화된 편집 지시를 JSON으로 남기게 한다는 패턴이다. 영상 편집뿐 아니라 기존 데스크톱 도구를 에이전트에 물릴 때 그대로 쓸 수 있다.
  • 선례도 있다. 클로드 코드에 프리미어·애프터이펙트를 붙여 컷편집과 자막을 자동화한 사례들이 이미 돌고 있어서, OpenScreen 조합도 무리한 시도가 아니라는 판단.
AI가 만든 화면이 촌스러운 이유는 취향이 아니라 목록이다
  • 모델들이 대체로 같은 SaaS 템플릿을 학습했기 때문에, 별 지시 없이 UI를 시키면 매번 같은 자리에 같은 표시가 난다. Impeccable이라는 오픈소스 도구가 그 표시들에 이름을 붙여 규칙으로 만들어 두었다.
  • 반복되는 클리셰 목록: 카드 왼쪽의 굵은 색 띠, 제목에 얹은 그라디언트, 보라에서 파랑으로 흐르는 배경, 색 배경 위의 회색 글자, 사방으로 퍼진 색 발광 그림자, 카드 안의 카드, 제목 위 작은 대문자 라벨, 그리고 Inter 폰트. 여기에 streamline, supercharge 같은 상투어가 겹친다.
  • 교정 방향도 단순하다. 색 띠 제거, 제목은 단색, 색 배경 위 글자는 회색 대신 흰색이나 배경의 짙은 계열, 카드 중첩은 여백과 얇은 구분선으로 대체, 폰트는 흔한 목록에서 벗어난다. 프롬프트 금지 목록으로 그대로 넣기 좋다.
곁가지: 만들 서비스에 맞는 배포 스택
  • Next.js 기반 SaaS·대시보드는 Vercel(배포·미리보기 편의, 개인은 무료로 시작 가능하지만 팀 운영부터 비용 증가), 회사 소개·블로그·행사 페이지는 Netlify(정적 사이트를 빠르게 올리고 관리도 단순).
  • 로그인·회원정보·게시글 저장이 필요하면 Supabase(MVP는 무료, 운영 단계에서 DB 비용 고려), 해외 트래픽·보안이 중요하면 Cloudflare(무료 범위가 넓고 트래픽 비용도 비교적 낮음).
읽을 때 걸러낼 부분
  • 같은 스레드 안에 기획 SaaS 홍보성 코멘트와 필요했는데 감사합니다 류 반응이 섞여 있다. 실제 정보는 OpenScreen 한계 보고, MCP 내장 구현 후기, Impeccable 규칙 목록 세 갈래에 몰려 있다.
