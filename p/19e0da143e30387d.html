핵심 포인트

요지
  • Anthropic이 직접 만든 공식 무료 학습 코스가 13개 공개되어 있고, 수료증까지 발급된다. 3자 제작 강의나 유튜브 짜깁기가 아니라 Claude를 만든 팀의 1차 자료라는 점이 이 링크의 유일한 값이다.
  • 게시물 자체의 분석은 얇다(구성은 목록 + 순서 추천). 대신 흩어져 있던 코스 URL을 한 곳에 모아 트랙별로 정렬해 준 인덱스로서 쓸모가 있다. 2026-07-31 기준 13개 링크 전부 살아 있음을 확인했다.
입문·공통 트랙
  • Claude 101, 일상 업무용 입문. 첫 진입점으로 지목된 코스.
  • AI Fluency: Frameworks and Foundations, 도구 사용법이 아니라 AI와 일하는 사고 프레임을 다룬다.
  • Introduction to Agent Skills, 반복 작업을 스킬로 묶는 개념. 지금 Claude Code 스킬 구조를 쓰고 있다면 공식 정의를 맞춰보는 용도로 값이 있다.
개발자 트랙
  • Building with the Claude API, 제품에 붙이는 쪽. 프롬프트 캐싱·툴 사용 같은 API 레이어 관심사가 여기 모여 있다.
  • Claude Code in Action. 원 게시물이 개발자에게 Claude 101 다음 바로 넘어가라고 지목한 코스다.
  • Introduction to Model Context Protocol, 외부 도구 연결의 공식 설명.
  • MCP Advanced Topics. MCP 서버를 이미 붙여 쓰고 있다면 입문편을 건너뛰고 이쪽만 봐도 된다.
그 외 트랙
  • 교육·비영리용 4개: AI Fluency for Students, AI Fluency for Educators, Teaching AI Fluency, AI Fluency for Nonprofits.
  • 클라우드 연동 2개: Claude with Amazon Bedrock, Claude with Google Cloud Vertex AI. 사내 인프라가 이미 두 클라우드 중 하나라면 이쪽이 가장 바로 쓰인다.
읽는 각도
  • "Claude를 잘 쓴다"의 정의를 프롬프트 작성에서 업무 맥락 구조화 + Claude Code 흐름 + API 통합 + MCP 연결 + Agent Skills 자동화로 넓혀 잡은 것이 이 게시물의 실제 주장이다. 코스 목록은 그 주장을 뒷받침하는 근거로 배치되어 있다.
  • 게시물 끝의 팔로우 유도는 걸러 읽으면 된다. 링크 13개는 공식 도메인이라 출처 리스크가 없고, 검증 비용도 낮다.
  • 코스 목록 자체는 시간이 지나면 갱신되므로, 개별 링크보다 skilljar 카탈로그를 북마크하는 편이 오래 간다.
