Zed의 Terminal Threads: 요금제 한 줄이 에디터와 터미널의 경계를 밀었다

65추천도 실용성 20/25 · 신규성 10/15 · 최신성 3/10 · momentum 7/10
깊이 11/15 · 지속가치 9/15 · 신뢰도 5/10

핵심 포인트

무엇이 생겼나
  • Zed가 Terminal Threads를 붙였다. 에디터 사이드바 안에서 claude, codex cli, opencode, cursor agent 같은 CLI 에이전트를 실제 터미널 프로세스로 띄운다. 프로토콜을 경유하지 않으니 평소 쓰던 스킬·훅·서브에이전트·`~/.claude`의 MCP 서버 설정이 하나도 깎이지 않고 그대로 들어온다.
  • 노리는 자리가 명확하다. 멀티 세션(한쪽은 기능 구현, 한쪽은 버그, 한쪽은 테스트)이 기본값이 된 지금, Electron 기반 에디터의 메모리가 병목이라는 것. 글은 Antigravity가 유휴 상태로도 램 1GB 초과, Cursor는 긴 세션에서 보조 프로세스만 7GB를 넘겼다는 사용자 보고를 든다. 에이전트마다 자기 언어 서버 프로세스를 따로 띄우는 구조가 원인이다.
진짜 포인트: 기능이 아니라 과금이 통합 방식을 정했다
  • Anthropic이 6월 15일부터 구독 사용량 풀을 쪼갰다. Agent SDK, `claude -p`, GitHub Actions, 그리고 구독 인증을 거치는 서드파티 에이전트가 풀에서 빠져 별도 크레딧으로 넘어가고, 그 크레딧은 API 정가로 깎인다(Pro 약 29,200원, Max 5x 약 146,000원, Max 20x 약 292,000원어치). 반대로 터미널에서 대화형으로 쓰는 Claude Code는 그대로 구독 안에 남는다.
  • 그래서 Zed에서 ACP로 Claude Code를 붙여 쓰던 경로는 '프로그램을 경유하는 사용'으로 분류돼 크레딧 쪽으로 넘어간다. Zed는 자사 블로그에서 이 경로가 헤비 유저 기준 15배에서 30배까지 비싸진다고 적었다.
  • 결론이 여기서 나온다. 기존 Claude 구독을 그대로 쓰면서 Zed에서 Claude Code를 굴리는 길은 Terminal Threads 하나다. 즉 이 기능은 신기술이나 기능 욕심에서 나온 게 아니라 요금제를 가르는 한 줄이 끌어낸 것이다. 도구의 모양을 바꾸는 손이 항상 기술 쪽에 있지는 않다는 사례로 읽을 값이 있다.
ACP 대 직접 터미널, 트레이드오프
  • Zed는 ACP를 버리는 구도가 아니라고 선을 그었다. ACP로 연결한 에이전트는 편집·리뷰 흐름에 더 깊게 붙고(diff 펼치기, 파일 트리, 문서 병렬 확인), Terminal Threads는 자유도와 무손실 호환을 준다. 깊은 통합이냐 원본 그대로냐의 선택으로 정리된다.
  • ACP를 연동 계층으로 보는 시각은 에디터 밖에서도 반복된다. 같은 글타래에 붙은 다른 논의는 Cursor·Codex·Claude Code 사이 핸드오프를 다루면서, 도구마다 어댑터를 새로 만들지 않으려고 ACP를 통합 계층으로 쓰는 방안을 검토한다. 넘길 상태는 세 묶음(AGENTS.md 같은 저장소 장기 맥락, git과 작업 트리의 실제 상태, 이전 에이전트와의 대화·진행 상황)으로 나누고, 두 번째 에이전트는 코드를 쓰기 전에 현재 diff·미커밋 파일·미실행 테스트를 확인했다는 기록을 남긴다.
반대 의견도 있었다
  • 댓글에서 갈린 지점. Zed를 쓰다 Warp로 옮긴 쪽은 '에디터는 에디터 기능에 충실해야 하는데 에이전트 뷰가 들어와 어지럽다', '가벼움이 매력이었는데 점점 무거워진다'고 짚는다. 편의성이 VS Code를 못 따라온다는 지적도 나온다. 가벼움을 명분으로 들어온 기능이 정확히 그 가벼움을 깎을 수 있다는 반론이다.
지금 뭘 할까
  • 이 글은 2026-05-22 시점이라 언급된 6월 15일 개편은 이미 적용된 상태다. Zed나 다른 에디터에서 구독 인증으로 에이전트를 붙여 쓰고 있다면, 사용량이 구독 풀이 아니라 크레딧으로 빠지고 있는지 먼저 확인하는 게 순서다. 붙이는 방식만 바꿔도 요금 구간이 달라진다.
  • 원문(Zed 공식 블로그)에서 Terminal Threads 설정과 지원 에이전트 목록을 직접 확인하는 편이 정확하다.
