안드레이 카파시가 공개한 AI 사용법, 10분 음성 램블

66추천도 실용성 20/25 · 신규성 8/15 · 최신성 6/10 · momentum 7/10
깊이 8/15 · 지속가치 11/15 · 신뢰도 6/10

핵심 포인트

핵심 워크플로우
  • 카파시는 뭔가 시킬 때 프롬프트를 정성껏 다듬지 않는다. 등을 뒤로 젖히고 음성 입력(/voice)으로 전환한 뒤, 10분 정도 의식의 흐름대로 정리 안 된 채 떠든다
  • 원문 표현으로는 'nice long ramble session'. LLM이 의도를 이해하려면 더 많은 비트가 필요한데 타이핑하기는 귀찮다는 문제를 음성으로 푸는 것
왜 작동하나
  • AI가 의도를 제대로 이해하려면 정보 조각이 더 많이 필요하다. 손으로 칠 때는 세 줄로 압축하던 것을 말로는 3분씩 풀어놓게 되므로 컨텍스트가 훨씬 풍부해진다
  • 정돈된 프롬프트 한 문단보다 정리 안 된 램블 10분이 모델에게 주는 신호량이 크다는 역발상. 프롬프트의 품질보다 컨텍스트의 양이 병목이라는 진단
인터뷰 변형
  • 일방적으로 쏟아내는 대신, AI가 '그건 왜요?' '이건 어떻게 하고 싶어요?' 하고 질문하게 두는 짧은 인터뷰 형태로도 운용한다
  • 혼자 말하면 중요한 걸 빼먹기 쉬운데, 질문을 받으면 미처 생각 못 한 부분까지 끌려 나온다. 이렇게 생각의 싱크가 맞으면 이후 결과물을 고쳐 쓰는 일이 확 줄어든다
바로 적용
  • 업무 고민을 음성으로 마구 덤프하고, AI에게 인터뷰를 시켜 컨텍스트를 채운 다음, 놓친 부분까지 정리하게 하는 것부터 시작해보기
  • Claude Code 같은 에이전트 작업에도 그대로 적용 가능. 요구사항을 압축해 쓰는 대신 배경, 제약, 실패 사례까지 말로 덤프하면 첫 결과물의 방향이 크게 좋아진다
