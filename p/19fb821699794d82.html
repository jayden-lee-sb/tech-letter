Clean Architecture Skills for Claude Code

58추천도 실용성 16/25 · 신규성 9/15 · 최신성 5/10 · momentum 6/10
깊이 6/15 · 지속가치 11/15 · 신뢰도 5/10

핵심 포인트

무엇인가
  • 국내 개발자 nathankim0이 로버트 마틴의 Clean Architecture 원칙과 켄트 벡의 리팩토링 철학을 Claude Code 리뷰·설계 스킬 2종으로 패키징한 오픈소스 repo (MIT, 84 stars)
  • plugin marketplace 구조라 스킬을 개별 설치할 수 있고, 코드 리뷰 시점에 원칙 위반을 잡아주는 리뷰어 역할로 동작
Clean Architecture 스킬
  • Dependency Rule 검사가 핵심: 소스 의존성이 항상 안쪽(고수준 정책)으로만 향하는지 확인
  • Entities · Use Cases · Interface Adapters · Infrastructure 4계층 구조 분석과 DIP를 이용한 계층 경계 통과 가이드, SOLID 점검까지 포함
  • 프로젝트 전체 아키텍처 리뷰, 특정 모듈 의존성 검사, 신규 기능 설계 유도까지 프롬프트 한 줄로 트리거
Kent Beck Style 스킬
  • code smell을 5분류(Bloaters, OO Abusers, Change Preventers, Dispensables, Couplers)로 탐지하고 Extract Method 등 구체 리팩토링 기법을 제안
  • YAGNI · KISS · Simple Design 4원칙과 의도가 드러나는 네이밍(intention-revealing code) 리뷰를 포함해, 아키텍처 스킬과 미시·거시를 분담
바로 써보기
  • Claude Code에서 /plugin marketplace add nathankim0/clean-architecture-skills 후 /plugin install clean-architecture@clean-architecture-skills 두 줄이면 끝
  • Cursor, Gemini CLI, OpenCode에도 스킬 폴더를 클론하는 방식으로 그대로 적용 가능
평가와 주의점
  • 내용 자체는 원전(클린 아키텍처, 리팩토링) 원칙의 체크리스트화라 새 지식이라기보다 AI 리뷰의 일관성을 확보하는 용도로 보는 게 정확함
  • 원 포스터는 마틴 파울러 리팩토링과 크리스토퍼 알렉산더의 원칙을 함께 넣어 리팩토링해 본 경험을 언급, 여러 거장의 원칙을 스킬로 조합하는 접근을 제안
  • 커밋 2개의 초기 단계 repo라 스킬 내용(SKILL.md)을 한번 훑고 팀 컨벤션에 맞게 포크해 쓰는 편이 안전
