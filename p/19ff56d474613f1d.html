diagram-design: 27종 다이어그램을 사이트 톤에 맞춰 뽑는 에이전트 스킬

55추천도 실용성 20/25 · 신규성 8/15 · 최신성 3/10 · momentum 6/10
깊이 7/15 · 지속가치 6/15 · 신뢰도 5/10

핵심 포인트

무엇인가
  • Claude Code용 다이어그램 스킬. 아키텍처·플로우차트·시퀀스·타임라인·조직도·벤 다이어그램 등 27개 타입을 지원
  • 타입마다 minimal light, minimal dark, full editorial 3가지 스타일로 출력하고 export로 PNG·SVG 저장
  • 4월에 올라온 저장소가 하루에 스타 1,612개를 받으며 뒤늦게 확산 (전체 스타의 약 1/4이 그날 몰림)
눈여겨볼 설계
  • 대상 웹사이트를 분석해 주요 색상·폰트를 뽑고 paper, ink, accent, muted 같은 역할 토큰으로 자동 매핑
  • 커스텀 색을 적용하기 전에 WCAG AA 대비를 자동 검증해 접근성 깨진 그림이 나오지 않게 막음
  • 강조 색 1개, 포컬 요소 1~2개, 4px 그리드 정렬을 강제. "가장 좋은 수정은 대개 삭제"라는 원칙을 규칙으로 박아 넣음
바로 써보기
  • 설치: /plugin marketplace add cathrynlavery/diagram-design 후 설치, 또는 클론 후 스킬 폴더에 심링크
  • "아키텍처 다이어그램 만들어줘"처럼 말하면 다이어그램 타입을 스킬이 골라줌. 설계 문서·PR 설명용 그림에 바로 투입 가능
인사이트
  • 핵심은 그리는 능력이 아니라 제약이다. 모델이 그림을 과하게 꾸미는 경향을 색 1개·포컬 1~2개 규칙으로 눌러 결과 품질의 하한을 올림
  • 브랜드 토큰 추출 + 대비 검증 조합은 다이어그램 밖에서도 재사용할 만한 패턴. 슬라이드·리포트 생성 스킬에도 그대로 옮길 수 있음
  • 같은 시기 Archify처럼 인터랙티브 HTML을 내는 스킬도 떴음. 정적 이미지가 필요하면 diagram-design, 클릭해 탐색할 공유물이 필요하면 HTML 계열로 나눠 고르면 됨
  • 소개글은 애그리게이터 계정의 요약이라 27종 지원·자동 타입 선택의 실제 품질은 README와 직접 실행으로 확인 필요
