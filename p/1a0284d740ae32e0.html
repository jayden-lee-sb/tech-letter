앤트로픽 사내에서 유행 중인 ELI5 스킬: 코드 파기 전에 그림 한 장부터

50추천도 실용성 18/25 · 신규성 7/15 · 최신성 3/10 · momentum 6/10
깊이 4/15 · 지속가치 7/15 · 신뢰도 5/10

핵심 포인트

무엇인가
  • Claude Code 팀 Thariq이 공개한 사내 유행 스킬. /eli5 뒤에 질문을 붙이면 글은 줄이고 그림을 키운 HTML 설명 자료 한 장을 생성
  • ELI5 = Explain Like I'm 5. 다섯 살에게 설명하듯 배경지식 없이 읽히는 수준을 목표로 함
어디에 쓰나
  • 이 모듈이 어떻게 도는지, 왜 이 설계를 골랐는지, 이번 장애가 왜 났는지를 코드 읽기 전에 그림으로 먼저 잡는 용도
  • 댓글 반응도 같은 지점: 설계가 머리에 안 들어올 때 전체 그림부터 보는 데 좋았다는 실사용 후기
  • 온보딩, 리뷰 전 맥락 공유, 장애 회고처럼 사람에게 구조를 전달해야 하는 순간에 특히 효과적
설치
  • claude plugin marketplace add anthropics/claude-plugins-community
  • claude plugin install eli5@claude-community (원글엔 설치법이 없어 댓글에서 보충됨)
읽는 법·한계
  • 원글은 소개 수준이라 프롬프트 구조나 생성 품질에 대한 근거는 없음. 직접 써보고 판단할 것
  • 그림 중심 요약은 이해의 출발점일 뿐 정확성 검증은 아님. 설계 판단 근거로 쓰기 전엔 코드와 대조 필요
  • 핵심 아이디어(설명은 텍스트보다 시각 자료 한 장)는 스킬 없이도 프롬프트로 재현 가능해 오래 쓸 수 있는 습관
